# 📋 چک‌یار (Chek-Yar)

**دستیار رایگان و متن‌باز محاسبه تاریخ سررسید و مبلغ چک، بر پایه تقویم شمسی**

دموی زنده: **[chekyar-site.vercel.app](https://chekyar-site.vercel.app/)**

چک‌یار برای حل دغدغه‌های روزمره‌ی کسبه، فروشندگان و هرکسی که با چک سروکار داره ساخته شده:
«این چک ۴۵ روزه کی سررسید میشه؟»، «اون روز تعطیله یا کاری؟»، «مبلغ رو چطور به حروف بنویسم؟»، «از این مشتری چندتا چک دارم و جمعش چقدره؟»

## ✨ امکانات

- 📅 **محاسبه‌گر سررسید چک** — تاریخ صدور + تعداد روز (۱۰ تا ۱۲۰ روزه یا دلخواه) → تاریخ دقیق سررسید شمسی و میلادی
- 🚦 **تشخیص تعطیلی رسمی** — چک روی تعطیلی افتاده؟ خودش میگه و اولین روز کاری بعدش رو هم پیشنهاد می‌ده
- 🗓️ **تقویم کوچک ماه** با علامت‌گذاری روزهای تعطیل و روز سررسید
- 💰 **تبدیل مبلغ به حروف** با انتخاب ریال یا تومان، به همراه معادل واحد دیگر (جلوگیری از اشتباه رایج ریال/تومان)
- 📖 **دفتر چک‌های مشتری** — ثبت چند چک با تاریخ و مبلغ مختلف، محاسبه‌ی خودکار:
  - جمع کل مبلغ
  - **تاریخ سررسید متوسط (میانگین موزون)** طبق روش کلاسیک حسابداری
  - لیست چک‌ها به ترتیب تاریخ با وضعیت هرکدام
- 🔢 وارد کردن تاریخ با «تعداد روز از امروز» به‌جای گشتن تو تقویم
- 📤 **اشتراک‌گذاری** نتیجه به‌صورت متن (مستقیم به واتساپ/تلگرام) یا عکس
- 💾 **ذخیره‌سازی خودکار** دفتر چک روی همون مرورگر (چیزی پاک نمیشه)
- 📱 قابل نصب به‌عنوان اپلیکیشن (PWA) روی اندروید و iOS

## 🛠️ ساخته‌شده با

فقط **React + HTML خام** — بدون فریم‌ورک سنگین، بدون نیاز به build، یک فایل `index.html` مستقل که هرجا (Vercel، Netlify، GitHub Pages) قابل میزبانیه.

- تبدیل تقویم شمسی↔میلادی به‌صورت دستی و تست‌شده (بدون وابستگی به کتابخانه‌ی خارجی)
- الگوریتم تبدیل عدد به حروف فارسی
- داده‌ی تعطیلات رسمی، هرساله نیازمند به‌روزرسانی (به بخش مشارکت نگاه کنید)

## 🚀 اجرای محلی

هیچ نصب یا بیلدی لازم نیست:

```bash
git clone https://github.com/YOUR_USERNAME/chekyar.git
cd chekyar
# فقط index.html رو تو مرورگر باز کنید، یا با یه سرور ساده سرو کنید:
npx serve .
```
